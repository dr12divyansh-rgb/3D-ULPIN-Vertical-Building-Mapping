# 3D-ULPIN-Vertical-Building-Mapping
3D ULPIN extends 2D Bhu-Aadhaar into volumetric space $(X, Y, Z)$ to assign unique digital IDs to stacked units in high-rises.Vertical Building Mapping uses LiDAR, drones, and BIM to map individual floors and basements, securing clear property titles, preventing fraud, and enabling precise taxation in multi-storey structures.
