--------------------------------------------------------------------------------
KEY FINDINGS
--------------------------------------------------------------------------------

1. STPLS3D training enables vehicle detection: 0% → 14.6% IoU
   The synthetic pipeline was completely blind to vehicles. Any STPLS3D
   training fixes this — the most critical practical improvement.

2. STPLS3D improves road segmentation: 14.9% → 36.2% IoU
   Real road data (with markings, curbs, varied widths) trains road
   detection much better than synthetic flat planes.

3. Mixed training does NOT outperform STPLS3D-only on real data
   Exp004 (mixed) achieves lower building IoU (41.1%) than exp003 (52.0%)
   on STPLS3D test. The synthetic building vocabulary does not transfer
   well to real-world building geometry.

4. Mixed training almost preserves synthetic building performance
   Exp004 achieves 88.1% building IoU on synthetic vs exp001's 91.4%
   (only -3.3 pp). But vegetation collapses to 3.6% vs 52.2%.

5. More training epochs needed
   Both exp003 (5 epochs) and exp004 (10 epochs) were using small chunk
   subsets (300/epoch). Loss was still decreasing at final epoch for both
   — more epochs would yield better results.

6. OneDrive path causes IO bottleneck (~1.7 s/step without preload)
   Preloading chunks into RAM eliminates this but requires ~63 MB extra
   RAM, which triggered OOM on the current machine with other apps open.

Experiment 005: XYZRGB Input (Mode B)

Change input_mode from "xyz" to "xyzrgb" in stpls3d_quick.yaml.
RGB color is already stored in all 7,509 chunk files.
The dataset loader already supports xyzrgb — no data preprocessing needed.

Expected improvement: +5-15% mIoU (literature estimate)
Color helps most for:
  - Road vs ground (road markings, asphalt color)
  - Vegetation recall (green color signature)
  - Vehicle detection precision (metallic colors)
  - Building vs vegetation boundary

One code change needed: make PointNet2Seg accept in_channel=6
(currently hardcoded to 3 in the first SetAbstraction layer)

Run command after that change:
  .venv\Scripts\python.exe ml\src\training\train.py
      --config ml\config\stpls3d_quick.yaml  [with input_mode: xyzrgb]
